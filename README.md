# وب‌سایت لیلا آبکه

وب‌سایت رسمی و راست‌چین دفتر حقوقی لیلا آبکه، ساخته‌شده با React و Vite.

## اجرا

```bash
npm install
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
npm run preview
```

## اتصال فرم مشاوره

فرم تماس برای اتصال به هر سرویس فرم یا API آماده است. آدرس endpoint را در متغیر محیطی زیر قرار دهید:

```env
VITE_FORM_ENDPOINT=https://example.com/api/contact
```

در نبود این متغیر، فرم در حالت نمایشی رابط کاربری اجرا می‌شود.
